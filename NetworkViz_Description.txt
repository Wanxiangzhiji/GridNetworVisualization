The Neural Anatomy of the Grid visualizes the Western United States power grid as a three-dimensional network of 4,941 nodes and 6,594 links. Nodes represent power stations and substations, while links represent connections in the historical, undirected, unweighted grid topology documented by the Network Data Repository. Using Python and NetworkX, I applied Louvain community detection (42 communities; modularity Q = 0.9359), computed node degree and approximate betweenness centrality, and constructed a three-dimensional spring layout initialized from a two-dimensional network layout. Community membership determines node color, degree influences node size, and pale highlights identify nodes with the highest approximate betweenness. Matplotlib and Plotly were used for the final cinematic image and its interactive companion, with subtle glow added for visual emphasis. The visualization reveals a branching, modular infrastructure network joined by structurally important paths. Spatial positions and glow are artistic and topological representations, not geographic coordinates, electricity flows, or measured physical risk.

Data source: Watts–Strogatz Western US Power Grid, via Network Data Repository (networkrepository.com/inf_power.php).
